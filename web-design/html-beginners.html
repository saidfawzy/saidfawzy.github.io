HTML for Beginners

A solid, step-by-step introduction to semantic web authoring using HTML5: understanding web mechanics, doctype declarations, standard document structure, text formatting tags, code editor setups, and organizing structured information with ordered, unordered, and definition lists.

المسار التأسيسي العملي والمبسط لتعلم بناء وتصميم صفحات الويب بلغة HTML5؛ يشمل فهم كيفية عمل مواقع الإنترنت والمتصفحات، هيكلة كود الصفحة الأساسي (Doctype, Head, Body)، استخدام وسوم تنسيق وعرض النصوص، جولة توجيهية وإرشادية في مسار التعلم، وبناء القوائم المنظمة والمرتبة.

Lesson 01

01 Introduction

Watch & Learn
▼

مقدمة الدورة والتعريف بأساسيات شبكة الويب العالمية؛ كيف تعمل متصفحات الإنترنت في قراءة الأكواد، ما هي لغة HTML ولماذا تعتبر الهيكل العظمي لأي موقع على الإنترنت، وتجهيز بيئة ومحرر كتابة الأكواد.

What You'll Learn:
  • Introduction to how the World Wide Web and web browsers render code.
  • Understanding HTML (HyperText Markup Language) and its foundational role.
  • Setting up your code editor environment and previewing your first file.
Lesson 02

02 Document Structure

Watch & Learn
▼

هيكلية وبنية مستند الـ HTML القياسي؛ شرح وسم إعلان نوع الوثيقة (<!DOCTYPE html>)، وسم الجذر <html>، قسم الرأس <head> والبيانات الوصفية، وقسم جسم الصفحة <body> الذي يحتوي على كل ما يظهر للمستخدم.

What You'll Learn:
  • The boilerplate architecture of a valid HTML5 document.
  • Understanding <!DOCTYPE html>, <html>, <head>, and <body>.
  • Setting page titles, character encodings, and language attributes.
Lesson 03

03 Formatting Text with Tgas

Watch & Learn
▼

تنسيق النصوص باستخدام وسوم الـ HTML؛ استعراض وسوم العناوين المتدرجة (<h1> إلى <h6>)، وسوم الفقرات (<p>)، وسوم التمييز والتوكيد (<strong>, <em>)، فواصل الأسطر، والخطوط الأفقية.

What You'll Learn:
  • Heading hierarchy: proper semantic use of <h1> through <h6>.
  • Paragraph blocks <p> and line break rules with <br> and <hr>.
  • Text formatting and semantic emphasis tags: <strong>, <em>, and <mark>.

Lesson 05

05 Lists

Watch & Learn
▼

تنظيم المحتوى باستخدام القوائم في HTML؛ بناء القوائم النقطية غير المرتبة (<ul>)، القوائم الرقمية المرتبة (<ol>)، عناصر القائمة (<li>)، والتعامل مع القوائم المتداخلة (Nested Lists) لبناء القوائم البرمجية وأشرطة التنقل.

What You'll Learn:
  • Creating unordered bullet lists with <ul> and list items <li>.
  • Structuring ordered numbered lists with <ol> and custom type attributes.
  • Building multi-level nested lists as the foundation for website navigation menus.
