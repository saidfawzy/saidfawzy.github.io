Database Fundamentals

A vendor-neutral foundational engineering masterclass deconstructing relational database architecture: understanding DBMS operations, conceptual Entity Relationship Diagrams (ERD), logical schema mapping, relational integrity constraints, Microsoft Access table building, and Structured Query Language (SQL) basics.

المسار التأسيسي الهندسي المتكامل لقواعد البيانات العلائقية (محايد ويصلح لأي نظام مثل SQL Server, Oracle, Access)؛ يشرح مفاهيم معمارية النظم (DBMS)، تصميم مخططات الكيانات والعلاقات (ERD)، التحويل إلى النموذج المنطقي، هيكلة الجداول والمفاتيح الأساسية والأجنبية، فرض قيود التكامل المرجعي، ومقدمة تطبيقية للغة الاستعلامات البنيوية (SQL).
