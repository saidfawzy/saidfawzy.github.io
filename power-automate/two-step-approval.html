Cloud Automation SharePoint Integration Hands-on Flow Architecture

Enterprise Approval Flowchart Architecture

An advanced cloud workflow automation masterclass: architecting a sequential two-tier approval engine connecting SharePoint Lists with Microsoft Power Automate. Learn how to trigger flows on item creation, route approvals across management levels, evaluate multi-outcome condition branches, and update live item audit trails.

ورشة عمل هندسية متقدمة لأتمتة دورات الموافقات والاعتمادات السحابية في بيئات العمل والمؤسسات؛ تشمل تصميم وتطبيق مسار موافقة ثنائي المراحل (Two-Step Approval Workflow) يربط قوائم SharePoint بمحرك Power Automate السحابي، معالجة الشروط المنطقية المعقدة، توزيع مهام الاعتماد للإدارة، وتحديث حالات الطلبات وسجلات التدقيق آلياً دون كتابة أكواد برمجية.

Lesson 01

Create 2 step Approval in SharePoint List using Power Automate Part 1

Watch & Learn
▼

الجزء الأول: تأسيس وبناء البنية التحتية لمسار الاعتماد؛ إنشاء وتجهيز أعمدة وحالات قائمة SharePoint List، إعداد المشغل السحابي (Trigger: When an item is created)، وبناء المرحلة الأولى من الاعتماد (First-Level Manager Approval) مع إرسال بطاقات الموافقة التفاعلية.

What You'll Learn:
  • Configuring SharePoint List metadata columns for approval tracking.
  • Setting up automated triggers on SharePoint list item creation.
  • Building Tier-1 approval actions and customizing notification parameters.

الجزء الثاني: بناء المستوى الثاني من الاعتماد وشروط اتخاذ القرار؛ التحقق من استجابة المستوى الأول، تمرير الطلب للاعتماد التنفيذي (Tier-2 Director Approval)، تحديث حالة العنصر في SharePoint إلى (Approved / Rejected)، وإرسال إيميلات الإشعار النهائي لجميع الأطراف المعنية.

What You'll Learn:
  • Evaluating Tier-1 approval responses using conditional branching logic.
  • Routing conditional requests to Tier-2 executive approvers dynamically.
  • Updating SharePoint list item status columns and dispatching automated outcome alerts.
