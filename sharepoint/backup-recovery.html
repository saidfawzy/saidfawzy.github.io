13 SharePoint Data Loss Disasters

An advanced systems engineering and administration masterclass exploring 13 catastrophic data loss scenarios in Microsoft SharePoint. Learn how to diagnose critical corruption, establish automated farm-level and granular backup strategies, navigate multi-stage recycle bins, and execute complete disaster recoveries.

Available both as a unified 1.5-hour complete masterclass and as detailed two-part hands-on modules covering disaster prevention, database backups, PowerShell routines, and live item-level restoration.

Lesson 01

13 SharePoint Data Loss Disasters

Watch & Learn
▼

The definitive full masterclass: an in-depth breakdown of 13 critical data loss scenarios across enterprise SharePoint deployments. Dissects user error, schema corruption, farm misconfigurations, orphaned assets, and presents battle-tested architectural recovery workflows.

What You'll Learn:
  • Comprehensive exploration of 13 primary data loss disaster patterns.
  • Understanding Central Administration vs. SQL Server database backup mechanics.
  • First-stage vs. Second-stage site collection recycle bin preservation rules.
  • Preventive policies, unattached content database recovery, and business continuity.
Lesson 02

Practical Backup & Restore in SharePoint 2010-2013 Part 1

Watch & Learn
▼

Module 1 of the practical series: configuring backup architectures, understanding farm topologies, setting up content database snapshots in SQL Server, and using Central Administration to plan full and differential backups.

What You'll Learn:
  • Setting up backup infrastructure and service account permissions.
  • Performing full farm backups via SharePoint Central Administration.
  • Database-level backup configurations in Microsoft SQL Server Management Studio.
  • Automating recurring backup schedules using PowerShell cmdlets (Backup-SPFarm).
Lesson 03

Practical Backup & Restore in SharePoint 2010-2013 Part 2

Watch & Learn

Module 2 of the practical series: step-by-step restoration procedures, recovering single site collections, exporting lists and libraries without downtime, and restoring data from unattached content databases.
