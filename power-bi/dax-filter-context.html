DAX Filter Context in Power BI

Master the mechanics of DAX Evaluation Context: Row Context, implicit and explicit Filter Context, iterators (SUMX), and modifying filter propagation using CALCULATE, ALL, and KEEPFILTERS.

Part 01

DAX Filter Context Part 1 (Arabic)

Watch & Learn
▼

تأسيس جوهري لمفهوم سياق الفلترة (Filter Context)؛ كيف يفكر محرك DAX عند تقييم المقاييس، الفرق بين سياق الصف (Row Context) وسياق الفلترة، وفهم مبدأ المصفاة (Filter then Calculate) لحساب مجاميع المبيعات ونسب المساهمة المئوية.

What You'll Learn:
  • Architecture of DAX Evaluation Context: Row Context vs Filter Context.
  • The golden rule: "Filter then Calculate" execution pipeline.
  • How Matrix rows, columns, slicers, and filter panes dynamically constrain measures.
  • Overview of the 9 course exercises and starter PBIX models.
Part 02

DAX Filter Context Part 2 (Arabic)

Watch & Learn
▼

تطبيقات عملية على سياق الفلترة التلقائي وسريان العلاقات (Filter Propagation)؛ كيفية انتقال الفلتر من جداول الأبعاد إلى جداول الحقائق، وتأثير وضع الحقول المختلفة في محاور المصفوفة والمخططات.

What You'll Learn:
  • How filters propagate across established 1-to-many model relationships.
  • Implicit filter context created by Matrix visual dimensions and hierarchies.
  • Hands-on analysis of base measure calculation across categorical cuts.
Part 03

DAX Filter Context Part 3 (Arabic)

Watch & Learn

التحكم الصريح في سياق الفلترة بواسطة دالة CALCULATE؛ تعديل الشروط، إلغاء الفلاتر باستخدام دالة ALL، وتطبيق مسائل حساب النسبة المئوية من الإجمالي الكلي (Percentage of Total).

DAX Filter Context Part 4 (Arabic)
