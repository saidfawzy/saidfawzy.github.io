Overview of Reporting in Power BI (Full Walkthrough Session)

Watch & Learn
▼

جلسة الويبينار الكاملة والمكثفة؛ استعراض الفروق الجوهرية بين Excel و Power BI، خطوات دورة حياة البيانات (ETL في Power Query)، ضبط أنواع البيانات ومعالجة القيم الفارغة (Nulls)، بناء نموذج العلاقات والمقاييس بـ DAX، تصميم لوحة معلومات الموظفين مع التنسيق الشرطي (Data Bars / Color Scales)، والتحكم في تفاعل العناصر (Edit Interactions)، ثم النشر السحابي ومشاركة التقارير عبر Power BI Service وبرنامج مايكروسوفت للمطورين.

What You'll Learn:
  • Power BI Architecture: Desktop vs Power BI Service vs Report Server.
  • ETL Transformation in Power Query: Data profiling, type setting, and error handling.
  • Data Modeling & DAX: Relationship cardinalities, measures vs calculated columns.
  • Interactive Visual Design: Bar charts, matrix styling, conditional formatting, and slicers.
  • Fine-tuning visual interactions: Edit Interactions (Filter, Highlight, None).
  • Cloud Deployment: Publishing to workspaces, mobile responsive views, and sharing roles.
